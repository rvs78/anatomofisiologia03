# DESIGN — Pissarra Quest · «Àlbum de cromos»

Mateix sistema que Vascular Quest i Sentits Quest: coberta indigo `#22194d`, pàgina groga `#f2b42c` amb trama, cara blanca `#fffdf8`, daurat `#ffd86b`, Big Shoulders Display + Atkinson Hyperlegible, cromos amb vora retallada, forats discontinus, sobre d'instruccions i moviment de `fx.js` sense canvis.

## Canvis respecte de Sentits Quest

| Element | Sentits Quest | Pissarra Quest |
| --- | --- | --- |
| Context | individual, ordinador | per equips, pissarra digital tàctil |
| Color de sistema | ull turquesa · orella coure | **color de l'equip a qui toca** (turquesa, coure, violeta, blau) |
| Làmina | model 3D (three.js) | SVG 2D fet a mà, cinc sentits |
| Etiquetes | dues columnes que segueixen el model | dues columnes; es prova cada repartiment esquerra/dreta i s'escull el que no té línies creuades ni línies sobre altres punts |
| Altres pantalles | test i text amb buits | emparellar, classificar en columnes i ordenar |
| Mides | px | `rem` amb escala per amplada; dins la làmina, `cqw` |
| Entrada | correu i contrasenya | nombre i noms d'equips, idioma, repetició de vista i oïda |
| Final | nota 1–10 i PDF a Classroom | podi, taula per pantalla, llista de repàs, impressió |
